SISTEMAS DE REPRESENTACIÓN NUMÉRICA

CONVERSIONES

De decimal a binario


  1. Divide el número decimal entre 2.
  2. Guarda el residuo (0 o 1).
  3. Divide el cociente nuevamente entre 2.
  4. Repite hasta que el cociente sea 0.
  5. El número binario será la lectura de los residuos de abajo hacia arriba.

De decimal a octal


  1. Divide el número decimal entre 8.
  2. Guarda el residuo.
  3. Divide el cociente nuevamente entre 8.
  4. Repite hasta que el cociente sea 0.
  5. El número octal será la lectura de los residuos de abajo hacia arriba.

De decimal a hexadecimal


  1. Divide el número decimal entre 16.
  2. Guarda el residuo (0-15, usando A-F para 10-15).
  3. Divide el cociente nuevamente entre 16.
  4. Repite hasta que el cociente sea 0.
  5. El número hexadecimal será la lectura de los residuos de abajo hacia arriba.
