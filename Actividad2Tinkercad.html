ACTIVIDAD 2

Encender un led si la distancia es mayor a 100cm y encender una alarma si la distancia es menor a 100cm

Esta actividad consiste en la implementación de un sistema con Arduino que permite medir la distancia mediante un sensor ultrasónico HC-SR04 y, en función de dicha medida, controlar el encendido de un LED y la activación de una alarma piezoeléctrica. Si la distancia es mayor a 100 cm, se activa el LED, mientras que si es menor, se activa la alarma.



OBJETIVOS


Objetivo General

Desarrollar un sistema electrónico que utilice un sensor ultrasónico para medir distancia y, mediante una función única, controlar el encendido de un LED y la activación de una alarma según la distancia detectada.

Objetivos Específicos
  • Conectar correctamente el sensor ultrasónico, LED y piezoeléctrico al Arduino.
  • Programar la medición de distancia mediante el sensor HC-SR04.
  • Implementar una función que controle simultáneamente el encendido y apagado del LED y la alarma según la distancia medida.

Materiales y Equipos

  • Computadora con acceso a Tinkercad Circuits (para simulación)
  • Arduino UNO
  • Sensor ultrasónico HC-SR04
  • LED
  • Resistencias
  • Protoboard
  • Piezoeléctrico (buzzer)
  • Cables

PROCEDIMIENTO


  1. Conectar el sensor ultrasónico: Trig al pin 9 y Echo al pin 10, conectar el LED al pin 2 con su resistencia y conectar el piezoeléctrico al pin 3
  2. Establecer las conexiones de alimentación (5V y GND)
  3. Declarar constantes para los pines utilizados y configurar pines como entradas o salidas en setup()
  4. Implementar la función medirDistancia() para obtener lecturas del sensor
  5. Crear la función controlarEncendido() que activa LED o piezo según la distancia
  6. Establecer un umbral de 100 cm para cambiar entre los dos modos de alerta
  7. Verificar el correcto funcionamiento del sistema mediante la simulación

Utilizar una unica función para encender y apagar el led y la alarma

ANÁLISIS Y DISCUSIÓN

  • El sistema implementado demuestra eficazmente el principio de funcionamiento de los sensores ultrasónicos y su aplicación en sistemas de alarma.
  • El uso del puerto serial para mostrar las mediciones permite calibrar y verificar el correcto funcionamiento del sensor.
  • La implementación con delays de 500 ms proporciona un balance entre respuesta rápida y estabilidad en las lecturas, evitando activaciones erráticas por mediciones temporales.

CONCLUSIONES

  • Se implementó exitosamente un sistema de detección de proximidad con alertas visuales y sonoras
  • El sensor ultrasónico demostró ser efectivo para mediciones de distancia en diferentes rangos
  • La centralización de la lógica de control en una única función mejoró la claridad del código
  • El sistema responde adecuadamente a cambios en la distancia, activando las alertas correspondientes


APRENDIZAJE OBTENIDO

  • Implementación de funciones modulares en programación Arduino
