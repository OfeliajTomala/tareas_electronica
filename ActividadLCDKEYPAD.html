ACTIVIDAD 5


Sistema de inicio de sesión

Esta actividad implementa un sistema básico de inicio de sesión utilizando una placa Arduino, un display LCD y un teclado matricial (keypad). El sistema valida una contraseña predefinida y proporciona retroalimentación visual mediante el LCD y otros componentes



OBJETIVOS


Objetivo General

Desarrollar un sistema de autenticación que permita verificar credenciales mediante un teclado matricial y proporcione retroalimentación a través de una pantalla LCD y un led o una alarma

Objetivos Específicos
  • Configurar e implementar la comunicación entre el teclado matricial, el display LCD y la placa Arduino.
  • Programar la lógica de verificación de una contraseña predefinida de 3 dígitos.
  • Implementar un sistema de retroalimentación visual (LCD) y luminosa (LEDs) para indicar el éxito o fracaso en la autenticación con una alarma.

Materiales y Equipos

  • Computadora con acceso a Tinkercad Circuits (para simulación)
  • Arduino UNO
  • Display LCD 16x2
  • LED
  • Teclado matricial 4x4
  • Protoboard
  • Piezoeléctrico (buzzer)
  • Cables
  • Resistencia

PROCEDIMIENTO


  1. Conectamos los componentes de la siguiente manera:
    • LCD: 6 pines digitales (RS, E, DB4-DB7) en los pines del 2 al 7
    • Keypad: 4 pines analógicos (A0-A3) para filas y 4 pines digitales (8-11) para columnas
    • LED verde en pin 13 (acceso correcto)
    • Piezo en pin 12 (acceso incorrecto)
  2. Se configuraron las librerías LiquidCrystal.h para controlar el LCD y Keypad.h para gestionar el teclado matricial.
  3. Se definió una contraseña preestablecida: "123"
  4. Se implementó la captura de hasta 3 caracteres ingresados por el usuario
  5. Se programó la comparación entre la contraseña ingresada y la almacenada
  6. Se configuraron mensajes en el LCD ("Correcto"/"Incorrecto")
  7. Se implementó el control del LED verde para acceso concedido
  8. Se programó la activación del piezo con tono de alarma para acceso denegado
  9. Se verificó el funcionamiento del sistema ingresando contraseñas correctas (activación LED) e incorrectas (activación de alarma piezoeléctrica).

Crear un sistema de inicio de sesión si la contraseña es correcta mostrar en el LCD Correcto y encender un led, si es incorrecto encender una alarma y mostrar incorrecto en el LCD

Tiempo de respuesta

  • Tiempo de procesamiento: < 100 ms desde último dígito hasta respuesta
  • Duración feedback visual: 2000 ms para mensaje LCD
  • Duración LED: 2000 ms encendido
  • Duración alarma piezo: 2000 ms con tono intermitente

Observaciones de comportamiento

  • Respuesta inmediata al completar los 3 dígitos
  • Borrado automático de pantalla después de cada intento
  • Retroalimentación clara y diferenciada entre acceso concedido/denegado
  • Secuencia completa: entrada → procesamiento → respuesta → reset

ANÁLISIS Y DISCUSIÓN


  • La combinación de señales visuales y auditivas demostró ser efectiva
  • El 100% de los intentos fueron claramente identificables
  • Tiempos de respuesta adecuados para aplicación en tiempo real

CONCLUSIONES

  • Se implementó exitosamente un sistema de autenticación con retroalimentación multimodal que combina señales visuales (LCD, LED) y auditivas (piezo).
  • El sistema demostró 100% de efectividad en la diferenciación entre acceso concedido y denegado mediante señales multimodales.
  • Los tiempos de respuesta del sistema son adecuados para aplicaciones
  • La arquitectura implementada demostró ser robusta y confiable durante las pruebas repetidas.


APRENDIZAJE OBTENIDO


  • La importancia de cuantificar tiempos de respuesta y características de las señales para evaluar la efectividad del sistema.
  • Se desarrollaron habilidades para integrar y controlar simultáneamente diferentes tipos de actuadores (visuales y auditivos).
  • Se practicó la asignación eficiente de pines y recursos del microcontrolador para diferentes funcionalidades.
